# ProgramPost - Автоматизация постинга в социальные сети

Десктопное приложение на Python для автоматической генерации и публикации контента в Telegram, VK, Instagram и TikTok.

## Возможности

- **Генерация цитат** с помощью ИИ (Groq API)
- **Создание изображений** с цитатами на текстурированном фоне
- **Публикация в социальные сети:**
  - Telegram (каналы)
  - VK (группы)
  - Instagram (посты с фото)
  - TikTok (контент для ручной публикации)
- **Планировщик постов** - автоматическая публикация в заданное время
- **Модерация** - проверка контента перед публикацией
- **База данных** - хранение цитат и истории публикаций

## Установка

### Требования

- Python 3.9+
- macOS (для других ОС могут потребоваться изменения в путях к шрифтам)

### Шаги установки

1. **Клонируйте или скачайте проект**

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
```

3. **Активируйте виртуальное окружение:**

**macOS/Linux:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

4. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

5. **Настройте API ключи:**

Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте ваши API ключи:

```env
# Groq API для генерации текста (бесплатно)
# Получите ключ на https://console.groq.com/
GROQ_API_KEY=your_groq_api_key_here

# Telegram Bot API
# Создайте бота через @BotFather в Telegram
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHANNEL_ID=your_telegram_channel_id_here

# VK API
# Получите токен на https://vk.com/dev/access_token
VK_ACCESS_TOKEN=your_vk_access_token_here
VK_GROUP_ID=your_vk_group_id_here
VK_API_VERSION=5.199

# Instagram (через instagrapi)
# Используйте ваши учетные данные Instagram
INSTAGRAM_USERNAME=your_instagram_username
INSTAGRAM_PASSWORD=your_instagram_password
```

### Получение API ключей

Для работы приложения необходимы API ключи для используемых сервисов:

- **Groq API** - для генерации текста (бесплатно, регистрация на console.groq.com)
- **Telegram Bot API** - создайте бота через @BotFather
- **VK API** - получите токен на vk.com/dev
- **Instagram** - используйте библиотеку instagrapi с вашими учетными данными

⚠️ **Безопасность:** Используйте отдельные аккаунты для автоматической публикации.

## Использование

### Запуск приложения

**Важно:** Сначала активируйте виртуальное окружение, затем запускайте приложение:

**macOS/Linux:**
```bash
source venv/bin/activate
python main.py
```

**Windows:**
```bash
venv\Scripts\activate
python main.py
```

Для выхода из виртуального окружения используйте команду `deactivate`.

### Вкладки приложения

#### 1. Генерация
- Введите тему для цитаты или оставьте пустым для случайной темы
- Выберите платформы для публикации
- Нажмите "Сгенерировать цитату"
- Просмотрите превью изображения и текста
- Одобрите и запланируйте публикацию или перегенерируйте

#### 2. Цитаты
- Просмотр всех сохраненных цитат
- Добавление цитат вручную
- Каждая цитата содержит: текст, автор, описание с размышлениями

#### 3. Посты
- Просмотр всех постов (запланированных, опубликованных, с ошибками)
- Публикация выбранного поста прямо сейчас
- Удаление постов

#### 4. Планировщик
- Запуск/остановка автоматического планировщика
- Настройка времени публикации

## Настройка времени публикации

Время публикации можно изменить в файле `config.py`:
```python
POST_TIMES = ['09:00', '18:00']  # Измените на нужное время
```

## Генерация изображений

Изображения создаются автоматически с:
- Черным текстурированным фоном (эффект "пошарпанного")
- Цитатой по центру
- Автором в правом нижнем углу
- Размером 1080x1080 (оптимально для соцсетей)

## TikTok

Для TikTok реализована генерация контента для ручной публикации:

**Функциональность:**
- Генерация видео из изображения цитаты (вертикальный формат)
- Добавление музыки из файла (MP3, WAV, OGG, M4A)
- Генерация короткого заголовка
- Генерация описания с хэштегами
- Сохранение контента в специальную папку для ручной публикации

**Как использовать:**
1. Сгенерируйте цитату во вкладке "Генерация"
2. Выберите файл музыки (необязательно)
3. Нажмите "Сгенерировать TikTok контент"
4. Откройте папку с TikTok контентом
5. Загрузите видео в TikTok приложение
6. Используйте сгенерированное описание и хэштеги

## Troubleshooting

### Ошибка "Groq API key не установлен"
Убедитесь, что вы добавили `GROQ_API_KEY` в `.env` файл.

### Ошибка при публикации в Telegram
Убедитесь, что:
- Бот добавлен в канал как администратор
- Правильный `TELEGRAM_CHANNEL_ID` (обычно начинается с `-100`)

### Ошибка при публикации в VK
Убедитесь, что:
- Токен имеет права на публикация в стенах
- Правильный `VK_GROUP_ID`

### Ошибка при публикации в Instagram
- Убедитесь, что логин и пароль верны
- Instagram может требовать двухфакторную аутентификацию
- Используйте отдельный аккаунт
